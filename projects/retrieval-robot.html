SUMMER 2026 · ROBOTICS INTERN · IDAHO NATIONAL LABORATORY

MPTC Specimen Retrieval Robot

Reconfiguring existing robotic hardware and developing a unified operator interface to assist with retrieval of displaced irradiated specimens in a specialized test-cell environment.

Raspberry Pi Python PyQt5 Mobile Robotics Sensor Integration ROS 2 RViz pymycobot

01 / CONTEXT

The Engineering Problem

During my robotics internship at the Structural Properties Laboratory at Idaho National Laboratory’s Materials and Fuels Complex, I worked on a specimen retrieval system for the MPTC. The test cell uses Universal Robots (UR) robotic arms and other equipment to manipulate samples during testing. Small irradiated specimens may become displaced or fall, creating a need for a remotely operated retrieval approach.

02 / MY ROLE

System Integration & Operator Interface

I reconfigured existing components to create a mobile retrieval platform and used a Raspberry Pi as the central computer. I developed a Python/PyQt5 graphical interface that brought robotic arm control, rover movement, front and wrist camera views, and Geiger counter readings into one place. The goal was to make the separate subsystems more cohesive for operator use.

03 / INTERFACE

Centralized Retrieval Controls

The interface includes six robot-joint controls, gripper commands, rover movement buttons, two camera panels, and a radiation-monitoring area. Combining these functions allows an operator to view the work area and manage the robot from one application.

05 / TECHNICAL CHALLENGES

ROS 2 Compatibility & Adapting the Control System

One of the major technical challenges I encountered during this project was integrating the myCobot robotic arm with ROS 2. I initially used ROS 2 and RViz for robotic arm control and visualization. However, incompatibilities between the ROS version required by the robotic arm and the Linux environment caused recurring system crashes, preventing reliable operation.

I collaborated with IT to investigate the compatibility issues and evaluate possible solutions, including updating the Linux environment. However, institutional network security restrictions made the required update impractical within the internship's time constraints.

To overcome this challenge, I transitioned from ROS 2 to the pymycobot Python API, which allowed me to communicate directly with the robotic arm. I integrated this approach into my existing PyQt5 graphical user interface, enabling direct robotic arm control without relying on the incompatible ROS 2 setup.

This experience strengthened my troubleshooting and system integration skills and demonstrated the importance of adapting engineering solutions to real-world hardware, software, security, and time constraints.
